Lucky Manager Lab

Every manager below has zero true skill. Pick the one with the best Sharpe ratio and test it. How often does it look skilled?

Press “Run simulation”.

What you are seeing

Naive PSR: the best manager tested alone with the Probabilistic Sharpe Ratio (Bailey & López de Prado). Deflated: the same test after raising the bar to the Sharpe you would expect from the best of N skill-less managers (Deflated Sharpe Ratio). With 5 % tests and N = 50 the chance that some manager passes is 1 − 0.9550 = 92.3 %.

Limits

Independent managers, normal returns, 8 % annual volatility, no fees, no survivorship bias. Real universes are correlated and fat-tailed, which usually makes selection bias worse. Simulated data; not investment advice. The JavaScript is a port of manager-diligence, checked against the Python reference to 1e-9 with mutation tests.
