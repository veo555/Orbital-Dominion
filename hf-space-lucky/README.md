# Lucky Manager Lab
Interactive demo of selection bias in manager selection: simulate N managers with **zero** true skill, take the best, and see how often a naive Sharpe test is fooled versus the Deflated Sharpe Ratio.
JavaScript port of [manager-diligence](https://github.com/veo555/Orbital-Dominion/tree/HEAD/research/manager-diligence), verified against the Python reference (`tests/parity.js`, mutation-tested). Simulated data only; not investment advice.
