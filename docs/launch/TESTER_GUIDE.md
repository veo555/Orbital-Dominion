# Tester guide (give this to your first 10-20 players)

Thank you for trying Orbital Dominion. It is a research testbed: a real-time strategy game where AI agents play too. It takes 10-15 minutes.

1. Open the link. Phone or desktop both work. Nothing is installed or sent anywhere.
2. **Watch agents** (small link on the main menu): pick any two factions, press Watch, and follow one match for 3-4 minutes. Try 4x speed. Look at the graph and the "why" lines.
3. **Play a match** against the computer on Normal (start mission). The first minutes teach you the basics; press H for help.
4. Optional: try the same match code a friend sent you and compare notes.
5. File a **Playtest report** (GitHub -> Issues -> New issue -> Playtest report) or send the answers to whoever sent you the link. The five questions that matter most: Did it run smoothly? Did you play again without being asked? What stopped or confused you? What was the best moment? Did watching the agents teach you anything?

Please do not worry about being polite: the most useful reports are the blunt ones.
