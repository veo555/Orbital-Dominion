1. **Bio:** github.com -> your avatar -> Your profile -> Edit profile -> Bio (160 characters max). Suggested:
   `Quant researcher · stochastics, statistics, multi-agent systems · building Orbital Dominion, an open RTS testbed for game AI`
   Optional: Location, Website, Pronouns. Leave empty anything you want private.
2. **Pin only Orbital Dominion:** profile -> Customize your pins -> untick everything except `Orbital-Dominion` -> Save.
3. **Profile README:** create a new PUBLIC repository named exactly `veo555` (same as your username), tick "Add a README file", paste `PROFILE_README.md` (without the HTML comment), commit.
4. **Optional clean-up:** Settings -> your forked repos you do not use: archive them, or make them private (Settings -> Danger Zone -> Change visibility). Archiving keeps them but marks them inactive.
5. **Check:** open your profile in a private window and read it as a stranger would.
